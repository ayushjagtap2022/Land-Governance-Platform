Build the foundation and global layout for a React 18 + Vite + Tailwind CSS application: "National Digital Platform for Land Governance" (SIH PS 26019) for the Department of Land Resources (DoLR), Ministry of Rural Development, Government of India.

TECH STACK:
- React 18 (Vite)
- react-router-dom
- Tailwind CSS
- lucide-react

DESIGN RULES (STRICT INDIAN GOVERNMENT / NIC AESTHETIC):
- Do NOT use modern consumer SaaS styles: no purple/indigo neon gradients, no glassmorphism or backdrop-blur, no rounded-2xl or rounded-full buttons (use rounded-none or rounded-sm), and no dark mode.
- Base Theme:
  * Top utility bar: Light gray (#F1F5F9) accessibility strip with font-size controls (A- / A / A+), Language selector (English | हिन्दी), Screen Reader link, and a small Indian flag icon.
  * Primary Header: Deep Navy (#0F2C59 or #1E293B) with white text, containing the State Emblem of India placeholder, bilingual ministry text ("भू-संसाधन विभाग / Department of Land Resources | ग्रामीण विकास मंत्रालय / Ministry of Rural Development"), search bar, and user profile badge.
  * National Accent: A crisp 3px horizontal border below the header representing the Indian Tricolor (Saffron #FF9933, White #FFFFFF, Green #138808).
  * Page Background: Neutral off-white (#F8FAFC) with crisp 1px solid slate borders (#CBD5E1) around all tables and containers.
